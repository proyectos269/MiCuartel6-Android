# Mi Cuartel 6 Android 0.2

Primera versión de trabajo de la aplicación Android para Mi Cuartel 6.

## Objetivo

- Conectar con la API REST de Mi Cuartel 6 Integral.
- Autenticar al usuario mediante `/login`.
- Mantener la sesión mediante token Bearer.
- Consultar `/me`.
- Cargar los módulos autorizados mediante `/modules`.
- Cerrar sesión mediante `/logout`.

## Servidor

La aplicación está configurada para usar:
`https://sexta.cl/wp-json/mc6/v1`

## Estado

Versión 0.2 de desarrollo. Aún requiere compilación mediante Android Studio/Android SDK para generar el APK instalable.

La versión estable de Mi Cuartel 6 Integral que sirve de backend es la 3.103.
